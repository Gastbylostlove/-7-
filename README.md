# 🚀 SSOK (사장-알바 근무 및 급여 관리 시스템)

## 📖 프로젝트 소개

**SSOK**은 급여 명세서 작성과 교부의 어려움을 해결하기 위해 사장님과 직원의 근무·급여 데이터를 양방향으로 연동하여 스마트한 급여 관리를 제공하는 서비스입니다.

이 시스템을 통해 사장님은 직원의 근무 현황을 실시간으로 관리하고 급여를 정확하게 정산할 수 있으며, 직원은 자신의 근무 기록과 급여 내역을 투명하게 확인하고 선지급과 같은 편의 기능을 이용할 수 있습니다.

## ✨ 주요 기능

### 🌟 핵심 기능

**1. 실시간 근무 데이터 연동**
* 달력 API를 통해 사장님과 직원의 근무 데이터가 실시간으로 연동되어 관리가 편리해집니다.

**2. 자동 급여 계산**
* 연동된 근무 기록을 바탕으로 주휴수당, 세금 등을 포함한 급여가 자동으로 계산되어 정산 오류를 줄여줍니다.

* 계산된 급여 데이터가 임금명세서 양식에 자동으로 반영되며, 급여 이체 시 직원에게 손쉽게 전송할 수 있습니다.

### 🔎 세부 기능

#### 👨‍💼 사장님
* **근무 및 근태 관리:** 직원별 근무 상세 정보(시간, 메모) 및 실시간 출퇴근 현황을 확인합니다.
* **급여 관리:** 직원별 급여 내역과 상세 급여 명세서를 조회하고 관리합니다.
* **직원 관리:** 신규 직원을 시스템에 간편하게 등록하고 승인합니다.

#### 🧑‍🔧 알바
* **근무 정보 조회:** 자신의 일자별 상세 근무 기록과 주간 근무표를 확인합니다.
* **급여 정보 조회:** 매월 급여 내역과 상세 급여 명세서를 조회할 수 있습니다.
* **선지급 관리:** 급여 선지급을 요청하고 처리 현황을 확인합니다.

## 🛠️ 기술 스택

* **프론트엔드:** HTML5, CSS3, JavaScript
* **백엔드:** PHP
* **데이터베이스:** MySQL

## 📂 프로젝트 구조

```text
.
├── .env
├── connection_.php
├── connection.php
├── README.md
├── 사장-근무상세정보/
├── 사장-근무정보/
├── 사장-급여상세정보/
├── 사장-급여정보/
├── 사장-신규등록/
├── 사장-홈/
├── 사장님_근태및직원/
├── 알바-근무상세정보/
├── 알바-근무정보/
├── 알바-급여상세정보/
├── 알바-급여정보/
├── 알바-선지급관리/
├── 알바-홈/
├── lib/
└── schedule/
```

* **사장-** / **알바-** : 각 역할(사장, 알바)에 맞는 기능별 페이지 디렉토리입니다.
* **connection.php**: 데이터베이스 연결 설정을 담당하는 파일입니다.
* **lib/**: CSS, JavaScript 등 공통으로 사용되는 라이브러리 파일들을 포함합니다.
* **schedule/**: 근무 스케줄 관련 기능 파일을 포함합니다.
